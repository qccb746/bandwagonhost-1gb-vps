## 1GB 内存实际能跑什么

### 个人博客和小型网站

这是中文社区里讨论最多的场景，结论也比较一致：够用，但要做减法。搬瓦工中文教程站对建站最低配置的分析认为，LNMP 环境下 1GB 内存是跑 WordPress 这类博客程序“比较现实、也比较稳妥的底线”。Reddit r/webhosting 上有用户估算，1GB 内存的 VPS 跑一个不臃肿的 WordPress 站点，可以轻松应付 10 到 20 个并发访客。

想让 1GB 跑得稳，几个被反复验证的做法：MySQL/MariaDB 调小缓冲池、启用 OPcache、用页面缓存插件减少 PHP 动态请求、加 2GB swap 兜底（Linux 社区的经验值是 swap 设为内存两倍）。做到这几点，日均几千 PV 的静态化博客问题不大。

### 轻量代理

1GB 内存 VPS 的另一个高频用途。V2Ray、Xray、WireGuard 这类代理服务本身内存占用极低（几十 MB 级别），1GB 绰绰有余。实际上对代理场景来说，线路质量比内存重要得多——这也是很多人最终从 $49.99 基础款升级到 CN2 GIA-E 的原因：代理的体验瓶颈几乎从来不在 CPU 和内存，而在晚高峰的路由质量上。

### 自托管小工具和学习机

Pi-hole、Uptime Kuma、静态文件服务器、cron 任务机、Git 私有仓库、学习 Linux 的沙盒——这些服务的共同点是常驻内存占用低、并发接近于零。KVM 虚拟化意味着你有完整内核权限，Docker 也能装，但要注意容器化本身有额外内存开销（Reddit r/docker 上对低配 VPS 跑 Docker 的讨论基本是这个结论：能跑，但 1GB 上跑不了几个容器），1GB 机器更适合直接裸跑服务。

跑不动的也直说：大语言模型、大型数据库、Minecraft 多人服务器、编译大型项目。这些需求请直接看 4GB 以上的档位。

## 常见问题

**1GB 内存够跑 WordPress 吗？**
够，前提是做好缓存和数据库调优，适合个人博客量级的流量。要多站点的、流量大的，直接上 2GB 档（40G 套餐半年付 $52.99）。

**1GB VPS 能装 Docker 吗？**
能装能跑，但容器叠加的内存开销意味着你实际可用的服务数量比裸跑更少。1GB 机器建议直接裸跑。

**20G 硬盘会不会不够？**
对系统加一个博客或几个轻量服务来说够用。如果你要存文件、跑数据库、放媒体资源，考虑 40G 或 80G 档。

**买普通版以后能升级成 CN2 GIA 线路吗？**
线路类型跟套餐绑定，不能原地升级。想在基础款和 CN2 GIA-E 之间换，一般走“新购 + 数据迁移”或利用机房迁移功能换位置。所以如果国内线路对你重要，建议第一单就买对。

**流量超出 1TB 怎么办？**
超出后通常需要购买额外流量或等下月重置，具体以 KiwiVM 面板内的政策为准。轻量用途很难用满 1TB，但跑代理的话建议在面板里开着流量提醒。
